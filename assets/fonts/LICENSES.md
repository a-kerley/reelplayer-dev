# Self-hosted fonts

Downloaded from Google Fonts by `scripts/self-host-fonts.py` (latin +
latin-ext subsets only) so visitors' browsers never contact Google. All are
free to self-host and redistribute:

- SIL Open Font License 1.1 (https://openfontlicense.org): Inter, Open Sans,
  Lato, Montserrat, Poppins, Oswald, Merriweather, Playfair Display, Lora,
  JetBrains Mono, Khand, Hind Siliguri, Kalam, Karma, Rajdhani, Teko, Roboto
  (Roboto was Apache 2.0 before 2023 - either licence permits this use).

Each family's copyright notice is in its font file's metadata.
